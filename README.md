# TekTak_App
TekTak is the best video social media platform 

TekTak Application includes Google Auth, the ability to upload, publish, share, comment on, and like the videos; filtering by categories and advanced search functionalities, profile pages, suggested accounts, custom responsive design, and much more.

Technical Skills:
- TypeScript - one of the best open-source high-level programming languages today
- Advanced State Management of the entire React application 
- Next.js Best Practices such as file-based routing and data using server-side rendering and static generation
- Integrated OAuth to log in and register users using Google
- Managed the entire content of app using Sanity. Sanity is the unified content platform that’ll make the making of entire app possible
